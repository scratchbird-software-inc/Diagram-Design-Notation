# use-cases.1

Example-only addition to DDN 0.3.0-draft.1. The existing decoder, renderer and sketch modules are unmodified. All new SVGs are generated by those modules. `site/styles.css` scopes the preview sizing selector to its direct SVG child. This is not a fix for filesystem portal permissions.

The existing reference engine emits DDN-W901 for approximate text metrics and incomplete global routing. Six primary teaching views use explicit coordinates, while sixteen primary views use grids with no `at`, waypoint or callout coordinates.
