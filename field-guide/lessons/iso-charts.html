What this diagram shows

The standard chart marks — bars, pies, areas, treemaps — extruded into an isometric treatment with a declared depth field.

Why use it?

Presentations sometimes demand the 3-D look; doing it as a treatment over the same records keeps the data honest.

When is it useful?

Executive decks and posters, where the audience read the flat chart first.

How to read this example

  1. Heights and angles still encode the declared measure; depth is a second declared field, not decoration.
  2. Read values off the flat variants when precision matters — isometric projection distorts by design.

Information to gather first

  • The records
  • The measure and the depth field

How to author this view

  1. Open website/examples/basics/72-iso-charts.ddn and locate view iso_bar. This selects existing data; it is not a stored SVG.
  2. Inspect the chart.basic@1 profile and chart projection. Read the bindings before changing any value.
  3. Use the source-file picker or select a diagram element to find its declaration. Edit labels or values deliberately; keep identifiers stable unless all references are updated.
  4. Apply the source, inspect diagnostics, and compare the expected result. Export the SVG only after a successful render.

Boundaries and common mistakes

A rendering treatment over declared records; the data contract is identical to the flat charts.

  • Do not compare depths across panels — the projection is per-view.
  • Never let the treatment hide a smaller bar behind a larger one without saying so.
