What this diagram shows

Pools and lanes with tasks, gateways and events wired by sequence flow; the collaboration variant adds message flow between pools.

Why use it?

BPMN is the one process notation both the business and the workflow engine read — ambiguities surface as gateway questions.

When is it useful?

Any process that crosses team or system boundaries and needs an executable-adjacent reading.

How to read this example

  1. Sequence flow stays inside a pool; message flow crosses between pools.
  2. Gateway diamonds branch and join — read the gateway type marker before the labels.

Information to gather first

  • The activities
  • The events that start and end paths
  • The gateway logic

Boundaries and common mistakes

Declared BPMN with structural validation; no engine deployment or execution semantics are claimed.

  • Do not draw sequence flow between pools — that is what message flow is for.
  • A gateway without a default path deadlocks on the unlisted case.
