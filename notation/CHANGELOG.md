to `0.7.0` (designer `0.2.0`) with no language change — source versions stay
`0.2`–`0.5`, the core registry stays `ddn-core@0.3`. Since Beta 1 the runtime
gained compact authoring phases 1–5, view-level chrome options, isometric
depth, flow animation, worker-based rendering in the unified tool, a 10x
pure-JS routing performance round, and the keyed `replaceData` refresh
contract; every committed golden was regenerated by the 0.7.0 runtime and
the full `.ddn` corpus passes the normalize check (see the root
`CHANGELOG.md`).
