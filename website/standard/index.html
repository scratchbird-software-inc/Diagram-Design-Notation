Standard

A small language. Explicit contracts.

The adopted ddn-next-1 language and codex define source spelling, data, defaults and rules independently of any one application.

Readable authoring

Minimal examples with progressive detail.

How the contracts fit together

  1. A file declares one workarea and contains views, documents, definitions and data.
  2. The selected profile supplies method-specific rules and defaults.
  3. Elements and relations retain identity independently of appearances.
  4. Explicit file settings override eligible type-scoped CSS, then versioned standards.
  5. Verification reports logical consistency and completeness for the requested scope.

Version and release status

ddn-next-1 is the current implementation contract identifier. It is distinct from the deprecated prototype dialect. A change to standard defaults requires a new version; software upgrades do not silently alter an existing file’s defaults.
