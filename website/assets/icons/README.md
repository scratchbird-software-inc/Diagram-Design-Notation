# Example presentation artwork

This directory holds only artwork referenced by converted example content, including the original default icon bindings used by that content. No legacy parser or renderer is included.

[manifest.json](manifest.json) records each `library:item` key, site-relative file location, original viewBox, hash, example usage, existing license and available per-item provenance. [map.json](map.json) is the direct key-to-path map used by conversion. The `bindings` table in the manifest preserves only used default kind bindings.

The per-library NOTICE files retain the source pack attribution and license text. [GPL-2.0.txt](GPL-2.0.txt) preserves the original GPLv2 text for artwork identified as GPL-2.0-or-later. DDN and its original website material are GPL-2.0-or-later. Third-party artwork retains the individual licences recorded here.
