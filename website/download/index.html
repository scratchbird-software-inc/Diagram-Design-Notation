Download

ddn 0.8.0 — the open-source Diagram Design Notation project, sponsored by ScratchWeaver (ScratchBird Software Inc.) — is pre-1.0 and not yet published to the npm registry. Today you get it by cloning the repository; the runtime bundles below are also served directly from this site, and npm pack in notation/ produces the installable @ddn/notation tarball. The publish path is ready: CI runs npm publish --dry-run on every push and would publish on v* tags once the NPM_TOKEN secret is configured (it skips gracefully until then; the committed private: true is an accident guard stripped only by the tag-gated publish job). Embedding? Start from the embedding quickstart.

Clone the repository

git clone <repo-url> data-design-notation
cd data-design-notation
npm test          # full verification suite, exit 0 expected

Runtime bundles

Load ddn.global.js for everything, or compose the modular bundles (ddn-core → ddn-graph → ddn-projections/ddn-quality, plus the optional ddn-geo for map views and ddn-iso for isometric depth). Every bundle ships three formats: use the minified .min.js IIFEs for production embeds, the .mjs ES modules for modern bundlers and module pages (tree-shakeable; browsers need a static server for module imports — no file://), and the readable .js builds for debugging (source maps included). See the modules guide, the embedding quickstart and the embed example pages.

Field guide

The Diagram Field Guide (155 chapters) also ships as one portable, self-contained HTML file — the whole edition: live examples, guided edits and the full runtime inlined; save it and it works offline.

Reference

The element kind and relation reference lists every one of the 375 kinds and 185 relations with its rendered symbol, meaning and a paste-ready example — generated from the registry at every site build.

AI authoring reference

DDN-AI-REFERENCE.md (440 KiB, regenerated from the registry at every site build) is the whole DDN dialect in one file — vocabulary, properties, projections, all 475 diagnostic codes with fixes, the full grammar, and two dozen worked recipes — written so a chat AI can author valid DDN from it. How to use it:

  1. Download the reference file.
  2. Paste it into your AI chat (Claude, ChatGPT, …) or attach it as context.
  3. Describe the diagram you want in plain language — the AI writes the DDN source.
  4. Paste that source into the live tool — it renders immediately, and the validator catches anything the AI got wrong, by code.
