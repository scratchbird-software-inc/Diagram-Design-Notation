ScratchWeaver 0.6.0-beta.1 — the product name of this Diagram Design Notation (DDN) toolkit from ScratchBird Software Inc. — is pre-1.0 and private: true — it is not yet published to npm. Today you get it by cloning the repository; the runtime bundles below are also served directly from this site.

Clone the repository

git clone <repo-url> data-design-notation
cd data-design-notation
npm test          # full verification suite, exit 0 expected

Runtime bundles

Load ddn.global.js for everything, or compose the modular bundles (ddn-core → ddn-graph → ddn-projections/ddn-quality). Every bundle ships three formats: use the minified .min.js IIFEs for production embeds, the .mjs ES modules for modern bundlers and module pages (tree-shakeable; browsers need a static server for module imports — no file://), and the readable .js builds for debugging (source maps included). See the modules guide and the embed proof pages.
