Download

ScratchWeaver 0.7.0 — the product name of this Diagram Design Notation (DDN) toolkit from ScratchBird Software Inc. — is pre-1.0 and not yet published to the npm registry. Today you get it by cloning the repository; the runtime bundles below are also served directly from this site, and npm pack in notation/ produces the installable @ddn/notation tarball. The publish path is ready: CI runs npm publish --dry-run on every push and would publish on v* tags once the NPM_TOKEN secret is configured (it skips gracefully until then; the committed private: true is an accident guard stripped only by the tag-gated publish job). Embedding? Start from the embedding quickstart.

Clone the repository

git clone <repo-url> data-design-notation
cd data-design-notation
npm test          # full verification suite, exit 0 expected

Runtime bundles

Load ddn.global.js for everything, or compose the modular bundles (ddn-core → ddn-graph → ddn-projections/ddn-quality, plus the optional ddn-geo for map views and ddn-iso for isometric depth). Every bundle ships three formats: use the minified .min.js IIFEs for production embeds, the .mjs ES modules for modern bundlers and module pages (tree-shakeable; browsers need a static server for module imports — no file://), and the readable .js builds for debugging (source maps included). See the modules guide, the embedding quickstart and the embed example pages.
