Isometric load monitor — depth: "x_record.load" + keyed refresh

Synthetic demo over the minified production builds ddn-core.min.js + ddn-graph.min.js + ddn-projections.min.js + the optional ddn-iso.min.js (B1-034). The bar chart binds its extrusion depth to the record payload (depth: "x_record.load"); each tick pushes new cpu/memory/disk loads through ws.replaceData('load', rows) and re-renders, passing the previous committed depths as renderSync({isoFrom:{depths}}) so ddn-iso emits a short declarative SMIL transition (250 ms) per changed column. Model, view and layout are untouched — only the data block's record lines change.
