Quickstart — one script tag, global build

The minimal embed: load ddn.global.min.js (the all-in-one IIFE — everything except the optional geo module), hand DDNLive.createWorkspace your sources as text, render, and place the SVG. This page works over file:// — IIFE script tags need no server. The ten lines that matter:

<script src="ddn.global.min.js"></script>
<script>
  const ws = DDNLive.createWorkspace({ "model.ddn": sourceText });
  const r = ws.renderSync({ entry: "model.ddn", view: "overview" });
  document.getElementById("out").innerHTML = r.svg;
</script>
