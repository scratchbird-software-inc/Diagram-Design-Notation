Host round-trip — DDN in as a variable, DDN back out

The iframe runs the unified tool (tools/index.html) chromeless (?toolbar=off, drawers api). This page is the host: the textarea holds DDN source as a variable. Load into tool passes it in with DDNTool.setSource (a Promise that resolves after the render). Edit in the tool — the host-opened source drawer, or an appearance override — and every change notifies the host through DDNTool.onSourceChange (see the revision line). Read back updated DDN calls DDNTool.getSource({ includeAppearance: true }): the current presentation is serialized into the source with the same canonical save-serializer the tool's own Save path uses, so the text you get back re-renders exactly what you saw. Serve over HTTP (node tools/serve.js). Recipe: embedding.md → Passing DDN in and out.
