Serving note: browsers refuse ES-module imports over file:// (CORS), so open this page through any static server — from the repository root: node tools/serve.js, then http://127.0.0.1:8080/website/examples/embed/esm-module.html. The .min.js IIFE proof pages (core-graph, core-only-check, data-refresh) work over file://. If the status below mentions a fetch failure, you are reading this over file:// — the page itself is fine.
