Quickstart — projections-only page (chart, smallest render path)

A chart page does not need the all-in-one build: load ddn-core.min.js + ddn-graph.min.js (the renderer core requires the graph bundle even for charts) + ddn-projections.min.js. Skip ddn-quality and ddn-geo and the Studio component — roughly 740 KB of minified runtime instead of 805 KB for ddn.global.min.js (exact byte table on the download page). IIFE tags work over file://. Rendering a kind whose bundle is missing throws the coded DDN-E010 naming the bundle to add.
