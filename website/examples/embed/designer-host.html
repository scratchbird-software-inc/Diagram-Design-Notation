Embedded designer — the tool in ?mode=design, driven by its host

The iframe runs the unified tool as an embedded designer: ?mode=design&toolbar=off with host-openable drawers (drawers=source:api,…). Design mode is the viewer plus editing affordances: drag-to-pin is armed, the Add element palette (click-to-place) and Connect (click source → click target → pick a verb) sit on the stage, and the host drives everything else through the B1-050 I/O contract. The textarea holds DDN source as a variable. Load into designer passes it in with DDNTool.setSource. Edit visually in the frame — drag elements, place new ones, connect them — and every edit notifies the host through DDNTool.onSourceChange. Get edited DDN back calls DDNTool.getSource: the visual edits are in the text. Serve over HTTP (node tools/serve.js). Recipe: embedding.md → Embedding the designer.
