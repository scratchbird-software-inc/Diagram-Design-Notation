Host-controlled embedding — ?toolbar=off + api drawers

The iframe below runs the unified tool (tools/index.html) with ?toolbar=off&drawers=source:api: no icon toolbar at all, and the source drawer is in the api state — hidden from the user, not user-openable, but fully openable by host code through DDNTool.setDrawer. The buttons are this page's own chrome; the "files drawer" button demonstrates the misuse result for a none drawer. Serve over HTTP (node tools/serve.js) — cross-frame scripting and ?src= deep links are not available from file://. Recipe: embedding.md → Controlling the embedded tool.
