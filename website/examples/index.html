128 runnable .ddn sources — served raw for download. Open any of them one click in the unified diagram tool (and single-file ones in the designer) via the links below, or render with the CLI: node notation/cli/cli.js render website/examples/basics/01-customer.ddn --workspace website/examples/basics --out out.svg. The tool takes a ?src= relative-path deep link (tools/index.html?src=../examples/basics/01-customer.ddn&mode=explore) — serve the site over HTTP (npm run serve) for browser fetches. See the examples README and the rendered gallery.
