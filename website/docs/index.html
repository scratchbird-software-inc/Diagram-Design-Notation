Developer guide

Build with the DDN utilities.

The model, language and rule modules are independent of the browser. DOM adapters provide viewing and editing; the host supplies IO and authority.

Embed a viewer

Create a complete runtime, open source files and mount the read-only browser adapter.

Load only the required tools

Offline packs, shared modules and automatic diagram-family loading.

Module responsibilities

How parser, model, profiles, defaults, runtime, presentation and utility adapters fit together.

Author the source

Use the adopted dialect and property codex rather than the deprecated prototype language.

Local distributions

Open complete HTML utilities directly from disk or embed the shared module tree.

Choose the API for the responsibility

The viewer observes and captures. The designer applies authorized commands through the shared runtime. The verifier checks the selected scope and reports completeness and unsupported capabilities explicitly. Source parsing does not execute arbitrary scripts or fetch missing dependencies.
