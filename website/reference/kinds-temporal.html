Reference — Time & lifecycle kinds

These kinds capture data at a time: snapshots, backups, archives, timelines, recovery plans, retention rules. They make the difference between "a backup exists" and "a backup we can actually restore from" visible — coverage, window and policy are stated, not hoped for.

This page lists every Temporal element kind in DDN — 8 of them. Each one shows its symbol, what it means, what extra information it accepts, and a tiny working example. Every example on this page passes the tool’s own check and render steps.

Data snapshot (snapshot)

What it looks like. Drawn as a titled card in the Temporal family colour. Hand-drawn and neo styles redraw the same kind — style changes the look, never the meaning.

What it represents. A captured data state with timestamp or version and consistency scope.

What you can add. Everything optional: snapshot_at, recovery_window, cadence, plus description, maturity and uid.

Example — paste it into the tool’s source drawer and Apply
