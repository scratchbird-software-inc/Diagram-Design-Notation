Reference — Flow (data movement) relations

Flow relations say data moves this way: read, write, replicate, publish, load, sync. The arrow points the way the bytes travel. A flow says nothing about how it moves — mechanism, schedule and guarantees are separate properties, so “replicates” and “replicates every 5 minutes over TLS” are the same line with different notes.

This page lists every Flow relation in DDN — 34 of them. Relations are declared inside a data block: relation id "label" @from -> @to { kind: …; }. Every example on this page passes the tool’s own check and render steps.

Flow relations end in a filled arrow (forward payload movement). Cardinality marks are not allowed here — the line is about movement, not participation. Label the line with what travels (“orders”, “nightly snapshot”).

transfers data to (flow)

What it means. Source to destination; any transport is specified separately. It ends with a filled arrowhead — read it in the arrow direction: “From → To”.

Example — paste it into the tool’s source drawer and Apply
ddn "0.5";
module "wiki.ref.relations";

// transfers data to (flow) between two elements.
data demo {
    object from_side "From" { kind: object; }
    object to_side "To" { kind: object; }
    relation shows "transfers data to" @from_side -> @to_side {
        kind: flow;
    }
}
