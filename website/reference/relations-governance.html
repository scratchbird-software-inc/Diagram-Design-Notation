Reference — Governance & responsibility relations

Governance relations attach people and rules to things: owns, stewards, operates, grants, classifies, retains. They’re what turns an architecture sketch into something an organization can act on — every box with an owner is a box someone can be asked about.

This page lists every Governance relation in DDN — 14 of them. Relations are declared inside a data block: relation id "label" @from -> @to { kind: …; }. Every example on this page passes the tool’s own check and render steps.

Governance relations end in an open arrow pointing at the governed thing. No cardinality marks. Labels can carry scope (“production only”, “EU residents”).

owned by (owns)

What it means. Resource to accountable owner; do not reverse this without changing the verb. It ends with a open arrowhead — read it in the arrow direction: “From → To”.

Example — paste it into the tool’s source drawer and Apply
ddn "0.5";
module "wiki.ref.relations";

// owned by (owns) between two elements.
data demo {
    object from_side "From" { kind: object; }
    object to_side "To" { kind: object; }
    relation shows "owned by" @from_side -> @to_side {
        kind: owns;
    }
}

has direct report (reports_to)

What it means. Manager/lead to direct report in an organisational tree; direction is parent to child (like emb), so tree roots are nodes with no incoming reports_to edge. It has no arrowheads — the relation is symmetric in meaning; the label does the talking.
