Reference — Data structure kinds

These kinds describe how data is shaped — records, documents, arrays, maps, time series, files, buckets. They sit between the business concepts and any one database: a record shape can be true of a JSON payload, a table row and a message all at once. Reach for these when the question is "what does this data look like?"

This page lists every Data element kind in DDN — 41 of them. Each one shows its symbol, what it means, what extra information it accepts, and a tiny working example. Every example on this page passes the tool’s own check and render steps.
