Reference — Deployment & infrastructure kinds

These kinds are the physical world: clouds, regions, zones, hosts, containers, volumes, devices. They answer "where does it actually run?" Draw them for deployment views, network overviews and residency conversations — and remember a box around boxes only means a boundary if a kind says so.

This page lists every Deployment element kind in DDN — 20 of them. Each one shows its symbol, what it means, what extra information it accepts, and a tiny working example. Every example on this page passes the tool’s own check and render steps.

Cloud provider / cloud scope (cloud)

What it looks like. Drawn as a frame shape in the Deployment family colour. Hand-drawn and neo styles redraw the same kind — style changes the look, never the meaning.

What it represents. A declared cloud hosting scope; managed status is a separate property.

What you can add. Everything optional: provider, region, environment, location (local/cloud/edge), residency, plus description and uid.

Example — paste it into the tool’s source drawer and Apply
ddn "0.5";
module "wiki.ref.kinds";

// One Cloud provider / cloud scope (cloud) on its own, drawn by the default graph view.
data demo {
    object example "Cloud provider / cloud scope" { kind: cloud; }
