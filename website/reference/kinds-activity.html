Reference — Activity & process kinds

These kinds describe doing: activities, pipelines, jobs, runs, schedules — and the classic flowchart shapes (start, process, decision) that profiles like flow.basic@1 dress up. Use them whenever the diagram tells a story in time: steps, hand-offs, branches, retries.

This page lists every Activity element kind in DDN — 90 of them. Each one shows its symbol, what it means, what extra information it accepts, and a tiny working example. Every example on this page passes the tool’s own check and render steps.
