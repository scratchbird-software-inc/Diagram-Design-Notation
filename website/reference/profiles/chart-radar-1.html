Profile verification

  • Marks bar/line/area/point/pie/donut bind explicit selected records. Numeric values must be finite numbers; numeric strings are not coerced.
  • x is category/number/date; point requires numeric x, bar/pie/donut category. Line/area may use category, number or UTC date.
  • Zero-baseline and arc share rules remain mark-specific; unit declarations must agree with supplied record units.
  • aggregate none/sum/count/min/max/mean is available only on supported bar/arc/top-k paths, with contributor IDs preserved; count has no physical unit.
  • Explicit empty records is legal for bar/line/area/point; filtering a nonempty selection to nothing is an error. Missing error/skip is explicit.
  • Specialization mark radar uses channels: x y series. Shared zero-to-maximum radial scale across categorical spokes; one polygon per series. Missing values are not silently interpolated.
