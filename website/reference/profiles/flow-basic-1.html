Profile verification

  • Completed control flow needs a start and end; starts have no incoming and ends no outgoing control edge.
  • Every decision has at least two outgoing edges with distinct, nonempty author branch labels.
  • Every active node is reachable from a start and can reach an end; cycles are allowed when an exit remains possible.
