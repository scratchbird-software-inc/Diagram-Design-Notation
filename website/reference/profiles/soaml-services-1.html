Profile contract

soaml.services@1

Full SoaML 1.0.1 notation: participants and agents with «Service»/«Request» port decorations (conjugated interfaces), service interfaces and contracts (collaboration glyph with provider/consumer role rows), capabilities, message types, milestones, contract-typed assembly/delegation connectors with service↔request conformance, choreography binding to UML sequence or state machine views.

Profile verification

  • Participant/agent service and request ports have declared interface types. Pairing defaults to same type.
  • Explicit compatibility modes are same, specialization, realization and operation-coverage; apply the chosen bounded check without claiming behavioral substitutability.
  • Service contract provider/consumer rows preserve roles. Choreography references resolve to supported sequence/state-machine views.

Profile defaults

Explicit file settings override eligible CSS, then these profile defaults and the common standard apply. Unspecified semantic facts remain unspecified.
