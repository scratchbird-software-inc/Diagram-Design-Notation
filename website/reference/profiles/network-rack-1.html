Profile verification

  • Attachments terminate at a bus or a declared port under the registry contract.
  • A semantic bus node is distinct from an unsupported arbitrary routing-geometry junction network.
  • Rack slot declarations stay within the rack height and are unique in that rack.
  • Slot data is verified; exact 1U engineering geometry, power, weight and thermal calculations are not supplied.

Profile defaults

Explicit file settings override eligible CSS, then these profile defaults and the common standard apply. Unspecified semantic facts remain unspecified.
