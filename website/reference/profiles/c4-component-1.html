Profile verification

  • Visible participants use this subtype's explicit palette. No field endpoints or attribute compartments.
  • Relationships preserve labels and system/person identity; no model discovery is implied.
  • Replace context-only palette with the declared component palette. Exactly one frame scopes a selected container and covers its components; people/systems/stores can be external.
