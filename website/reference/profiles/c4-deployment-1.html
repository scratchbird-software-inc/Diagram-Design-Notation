Profile verification

  • Deployment and manifestation have different registered endpoint directions.
  • Communication-path ends may carry multiplicity/roles but no qualifiers.
  • Nesting frames scope to node/device/execution-environment elements; preserve 3D node and artifact document glyphs.
  • Reuse the named base machinery while retaining this profile identity, method route, styling scope and exclusions. Renderer reuse does not import unrelated method permissions.
