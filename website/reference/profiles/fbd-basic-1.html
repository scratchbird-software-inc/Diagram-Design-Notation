Profile contract

fbd.basic@1

IEC 61131-3 FBD: function blocks (rect with name/type header and typed pins), typed wire connections (BOOL/INT/DINT/REAL/TIME/STRING/WORD), negation bubbles on BOOL pins, feedback loops allowed. Ladder (LD) hosting follows in a later item.

Profile verification

  • Pins declare BOOL/INT/DINT/REAL/TIME/STRING/WORD; wire endpoint types match.
  • Negation is allowed only on BOOL pins. Feedback cycles are legal and do not trigger a generic DAG rule.
