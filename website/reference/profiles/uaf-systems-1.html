Profile verification

  • The systems palette contains its named domain roles. Cross-domain UAF context can be selected explicitly without changing those role identities.
  • Every UAF verb keeps the exact registry source/target sets; shared arrow artwork does not widen them.
  • Roadmaps, forecast tables and dictionaries can reference separate timeline/table views; those projections are not silently enabled inside this graph profile.

Profile defaults

Explicit file settings override eligible CSS, then these profile defaults and the common standard apply. Unspecified semantic facts remain unspecified.

  "projection.kind": "graph",
