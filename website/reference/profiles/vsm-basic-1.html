Profile contract

vsm.basic@1

Value stream mapping (machinery): process boxes with data rows, the VA/NVA timeline ladder strip, inventory triangles, push/pull and material arrows, electronic/manual information arrows, supermarket, kaizen burst and operator glyphs — simple generic glyphs only; detailed industry icon artwork is a separate excluded task.

Profile verification

  • Only process nodes carry VA/NVA durations; values are finite nonnegative numbers with declared units.
  • Render the supplied timeline ladder strip, inventory and generic process/flow glyphs. No measured production simulation or detailed industry artwork is inferred.

Profile defaults

Explicit file settings override eligible CSS, then these profile defaults and the common standard apply. Unspecified semantic facts remain unspecified.

{
  "projection.kind": "graph",
  "projection.profile": "vsm.basic@1"
}
