decision.rules@1

Typed conjunction predicates; unique/first/collect hit policies; bounded partition proof and evaluation.

Primary palette

rule.row

Profile verification

  • Declare 1..8 input domains: enum (1..30 unique nonnull scalar values), boolean, or finite closed numeric interval; optional/null states are explicit.
  • Rules are conjunction records with eq/in/interval/null/missing predicates; omitted input predicate means unrestricted within its domain. Outputs name 1..20 unique keys and every rule supplies each finite scalar output.
  • unique/first/collect have bounded local matching semantics. priority/any/output_order/rule_order/aggregation retain the currently supplied table annotations and matching order, without claiming a complete DMN evaluator.
  • Coverage is complete/report/none. Partition numeric domains at predicate boundaries; budget 1..50000, default 4096. Exhaustion is UNKNOWN/budget_exceeded, never a proof; unique or complete obligations fail closed.

Profile defaults
