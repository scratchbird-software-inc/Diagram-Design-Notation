Profile verification

  • Select one quality.effect and a cause→parent relation. First-level ribs are 1..12 quality.category nodes.
  • Traversal is acyclic, at most four cause levels and 250 occurrences; selected causal relationships cannot form disconnected components.
  • A shared cause may occur on multiple branches with the same semantic ID and different occurrence IDs.

Profile defaults

Explicit file settings override eligible CSS, then these profile defaults and the common standard apply. Unspecified semantic facts remain unspecified.
