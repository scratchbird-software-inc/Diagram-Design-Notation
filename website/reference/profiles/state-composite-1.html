Profile contract

state.composite@1

Composite states as frames containing substates; dashed parallel regions; boundary-crossing transitions with event/guard labels.

Profile verification

  • Frames define composite regions with at most one initial marker per region.
  • Preserve region nesting and transition labels; do not apply the flat trace evaluator to a hierarchical diagram.

Profile defaults

Explicit file settings override eligible CSS, then these profile defaults and the common standard apply. Unspecified semantic facts remain unspecified.

  "projection.kind": "graph",
