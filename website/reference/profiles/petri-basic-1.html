Profile contract

petri.basic@1

ISO/IEC 15909 Petri net notation: places (circles) with token counts, transitions (bars), weighted arcs, inhibitor arcs (open-circle end), test/read arcs (dashed), markings via records. Bipartite graph enforced: places connect only to transitions and vice versa.

Profile verification

  • Arcs are bipartite between place and transition; each registered arc role retains its direction.
  • Token counts are integers >=0; explicit arc weights are integers >=1, not zero.
  • Draw place markings and transition bars; inhibitor and test arcs remain separate verbs.
  • Weight metadata applies to petri.arc and petri.testarc; inhibitor arcs do not accept a weight field. Tokens metadata belongs only to petri.place.
