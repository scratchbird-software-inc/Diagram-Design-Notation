Profile verification

  • Separate attribute and operation rows with declared visibility; retain classifier kinds and package/component glyphs.
  • Generalization is acyclic and same-kind; apply exact registry endpoint restrictions to every verb.
  • Package ownership must be acyclic; private imports and ancestor merge violations are rejected.
  • Optional provided/required interface assertions use the declared interface graph; they do not prove behavior compatibility.

Profile defaults

Explicit file settings override eligible CSS, then these profile defaults and the common standard apply. Unspecified semantic facts remain unspecified.

Design operations

  • Create classifier/package, edit ordered members, connect classifier relations and interfaces.
  • Set package ownership and interface assertions explicitly; nesting alone does not invent ownership.
Bounded analysis

Structural verification and display only; no execution or implied process engine.
