Profile contract

org.tree@1

Single-root reporting hierarchy of org/team/role participants, rendered with the native tree layout.

Profile verification

  • Exactly one root, no directed cycle and no node with multiple incoming managers.
  • Preserve current role direction manager → report; the proposed generic reports-to pattern has the reverse direction and cannot be substituted blindly.

Profile defaults

Explicit file settings override eligible CSS, then these profile defaults and the common standard apply. Unspecified semantic facts remain unspecified.

{
  "projection.kind": "graph",
  "projection.profile": "org.tree@1",
  "layout.algorithm": "tree"
}

Design operations

  • Create participant; connect manager to report; reparent by replacing the old incoming link in the same edit.
Bounded analysis

Structural verification and display only; no execution or implied process engine.

Outside this profile

  • matrix organizations (multiple parents)
  • dotted-line reports
  • HR-system synchronisation
