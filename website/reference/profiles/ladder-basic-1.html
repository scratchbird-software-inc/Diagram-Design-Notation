Reference / Profiles

Profile contract

ladder.basic@1

IEC 61131-3 LD: power rails, rungs (one data block per rung, declaration order top to bottom), NO/NC contacts, output coils (normal/set/reset/negated) right-aligned at the rail, parallel OR branches inferred from series topology, fbd.block/fbd.variable hosted on rungs, labels/jumps/returns. Dedicated rung layout algorithm (layout.algorithm: ladder).

Profile verification

  • Each data block is one rung, in declaration order; exactly one output coil per rung.
  • Series links stay in the same rung; parallel OR branches follow declared topology. Jump target is a selected label.
  • Require ladder layout; render rails and right-aligned coil, contact/coil variants and hosted FBD pins.
