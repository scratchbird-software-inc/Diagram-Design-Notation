Reference — Evidence & documentation kinds

These kinds are the honest margin notes of a model: notes, samples, fixtures, decisions, open issues, observations. They matter because diagrams lie by omission — an issue box says "this is not decided yet" in a way a missing box never can.

This page lists every Evidence element kind in DDN — 11 of them. Each one shows its symbol, what it means, what extra information it accepts, and a tiny working example. Every example on this page passes the tool’s own check and render steps.

Note / explanation (note)

What it looks like. Drawn as a note shape in the Evidence family colour. Hand-drawn and neo styles redraw the same kind — style changes the look, never the meaning.

What it represents. Non-executable explanatory material attached to a model element.

What you can add. Everything optional: source, observed_at, confidence, expected (for fixtures), state, and for samples the required columns: / rows: grid, plus description and uid.
