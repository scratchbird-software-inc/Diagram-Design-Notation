Reference — Annotation relations

Annotation relations attach commentary to the model: notes, examples, evidence, decisions, open issues. An annotation never changes what the model means — it explains it. Reach for these whenever the diagram needs an honest margin note instead of another fact.

This page lists every Annotation relation in DDN — 8 of them. Relations are declared inside a data block: relation id "label" @from -> @to { kind: …; }. Every example on this page passes the tool’s own check and render steps.

Annotation relations are plain lines (no arrow) — a note doesn’t act on anything. No cardinality marks. The note element itself carries the text.

Element kinds: all element families · relations overview: relations, the short version.

annotates · note illustrates · example supports assertion about · evidence records decision for · decision questions · issue tests expectation for · test appearance of · appear Annotates · flow.annotation

annotates (note)

What it means. Note to the element it explains. It has no arrowheads — the relation is symmetric in meaning; the label does the talking.

Example — paste it into the tool’s source drawer and Apply
ddn "0.5";
module "wiki.ref.relations";

// annotates (note) between two elements.
data demo {
    object from_side "From" { kind: object; }
    object to_side "To" { kind: object; }
    relation shows "annotates" @from_side -> @to_side {
        kind: note;
    }
}
