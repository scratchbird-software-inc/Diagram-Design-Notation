Try the interface looks

The interface theme changes the tools. Diagram backgrounds and typography stay in the document and retain their own appearance when exported.

Select a note, then choose Appearance & presets. Use Background, Font or Presets; drag the form title to move it. Sliders and precise number fields stay in sync. Apply commits one undoable source edit. Cancel keeps the original. Interface and UI colours customise the tools separately.

Local textures and fonts

Floating forms, complete controls

Backgrounds

Paper, linen, grid and dots; tint, scale, opacity and a repeatable seed. Workarea and element backgrounds have independent settings.

Local font suite

Inter, Source Serif 4, JetBrains Mono and Caveat. The optional page resource pack keeps fonts off the network.

Colour and stationery

A compact hex/RGB/alpha picker with swatches and Apply/Cancel, shared by appearance and paper settings.

User and company presets

Save a user preset in this browser, export it as JSON, or import a company pack. Imported company entries are read-only in the library; copy one into a new user preset to customise it. Applying a preset writes the chosen settings into the selected source scope. The existing file > CSS > standard hierarchy stays unchanged.

Download example company presets

Central company publishing, identity, permissions and mandatory brand policy belong to Weaver services. These standalone utilities consume portable packs without requiring those services.

Keep the resources with the page

The standard font pack uses seven variable WOFF2 faces across four families. Keep ddn-fonts.js beside the downloaded viewer/designer HTML. The core retains system fallbacks when the optional pack is absent. Custom WOFF2, WOFF, TTF and OTF files can be loaded locally and exported/imported as a font resource pack. SVG and PNG snapshots embed used local fonts and procedural textures.

Symbols, images and unboxed notes

Use an SVG or image as the element itself. In the designer, select the item and choose Symbol & label. Place its name at any of the eight outside positions, inside, or hide it. Connections attach to the image body independently of its caption. Text presentation provides transparent, unboxed annotations.
