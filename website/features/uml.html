UML 2.5.1 — all fourteen diagram families

Every UML 2.5.1 diagram family ships as a named, tested DDN profile. One end-to-end example per family is checked and rendered by the test suite. The known exclusions — no XMI/OCL exchange, no executable behavior, no conformance certification — are listed in plain language on the wiki exclusions page.

Class uml.structure@2

Types, attributes and operations with visibility, multiplicity and role names on association ends, aggregation and composition diamonds, navigability arrows, qualifiers, association classes, n-ary associations, generalization sets, templates, enumerations, derived members, and provided/required interfaces.

Profile plate · Example · Wiki guide

Object uml.object@2

Instances with underlined name : Classifier titles, slot values checked against the classifier’s datatypes, and instance links with multiplicity labels.

Profile plate · Example · Wiki guide

Package uml.structure@2

Package boxes with nesting, «import» / «access» / «merge» dependencies, and +/− visibility on packaged elements.

Profile plate · Example · Wiki guide

Deployment uml.deployment@1

Nodes, devices and execution environments as 3D boxes, artifacts as document icons, «deploy» and «manifest» dependencies, and communication paths with multiplicity.

Profile plate · Example · Wiki guide

Composite structure uml.composite@1

Parts inside classifiers (role: Type [multiplicity] rows), ports on boundaries, and connectors with role names and multiplicity.

Profile plate · Example · Wiki guide

Component uml.composite@1

Components with ports, assembly ball-and-socket connectors, delegation connectors, and provided/required lollipop-and-socket interfaces.

Use case uml.usecase@3

Actors, use-case ellipses with extension points, subject boundaries, include/extend/generalization, and extend conditions on the edge label.

Activity uml.activity@2

Actions, decisions vs merges, fork/join bars, object nodes, swimlanes, pins with parameter sets and streaming, send/accept signal pentagons, time events, flow final, interruptible and structured regions, exception handlers, and connector circles.

Profile plate · Example · Wiki guide

State machine uml.statemachine@1

States with entry/exit/do activities and internal transitions, history (H/H*), junction/choice/entry-point/exit-point/fork/join/terminate pseudostates, trigger [guard] / effect transitions, submachines, time events, composite states and parallel regions.

Sequence uml.sequence@2

Lifelines with combined fragments (alt/opt/loop/break/par and friends, nested, with guards), gates, creation and destruction, synchronous/asynchronous arrowheads, replies, lost/found messages, execution bars, time/duration constraints, and state invariants.

Communication uml.communication@2

Numbered messages on a graph layout, combined fragments around message groups, and {time}/{duration} constraints.

Interaction overview uml.interaction_overview@2
