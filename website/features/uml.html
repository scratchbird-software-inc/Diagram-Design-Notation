UML, with explicit boundaries.

The complete edition provides the adopted structural, behavioral and interaction profiles. Each profile documents its own roles and rules.

These are diagramming and bounded verification contracts. They do not imply full UML execution, all UML metamodel features or external certification.

uml.structure@1

Class/interface attribute and operation compartments; package tabs; component markers; generalization/dependency/realization.

uml.structure@2

uml.structure@1 plus UML 2.5.1 class notation: end roles/multiplicity/qualifiers (x_endlabels), aggregation/composition/navigability marks, association classes, n-ary junction (x_nary), generalization sets, templates, enumerations, provided/required interfaces, member adornments (x_member).

uml.deployment@1

UML 2.5.1 deployment diagrams: nodes/devices/execution environments (3D-box), artifacts (document icon), deploy/manifest dependencies, communication paths with multiplicity, node nesting via frames, deployed components.

uml.composite@1

UML 2.5.1 component + composite structure: ports on classifiers (SysML port machinery), assembly ball-and-socket connectors, delegation connectors, plain connectors with role names and multiplicity (x_endlabels), internal parts (x_part), collaboration occurrences (uml.collaboration).

uml.usecase@1

Actors, use-case ellipses, associations, include/extend/generalization.

uml.usecase@2

Adds subjects, extension-point targets, conditions and classifier generalization to the declared subset.

uml.usecase@3

uml.usecase@2 plus: extend conditions on the label; extension-point existence (DDN-PX004).

uml.sequence@1

Participants in declaration order with lifelines; messages in declaration order with dashed returns and activation bars; record provenance.

uml.sequence@2

uml.sequence@1 plus UML 2.5.1 interaction notation: combined fragments (nested, guards — x_fragment), gates, create/delete, synch/asynch/reply/lost/found message sorts, authorable activations, time/duration constraints, state invariants.

uml.communication@1

Graph layout of interaction participants; author-declared message numbers on relation edges; replies dotted under their request.

uml.communication@2

uml.communication@1 plus: x_fragment frames, {…} time/duration constraints on messages.

uml.object@1

Record instances naming a classifier; slots rendered as field rows; plain assoc links between instances.

uml.object@2

uml.object@1 plus: underlined instance titles, slot datatype checks, uml.link multiplicity.

uml.statemachine@1

Full UML 2.5.1 state machines: flat/composite vocabulary plus entry/exit/do activities and internal transitions, history/junction/choice/entry-exit-point/fork-join/terminate pseudostates, trigger [guard] / effect labels, submachines, time events.

uml.activity@1

Flow nodes plus fork/join bars and object nodes; swimlane partitions as view frames with declared node membership.

uml.activity@2

uml.activity@1 plus UML 2.5.1 activity notation: decision/merge distinction, pins with parameter sets and streaming (x_pin on ports), send/accept signal pentagons, time-event hourglass, flow final (⊗), interruptible regions with lightning edges, exception handlers, structured/expansion regions.

uml.timing@1

One band per participant; state plateaus from declared time points; numeric time axis; supplied data only.

uml.timing@2

uml.timing@1 plus: duration/slew annotations, x_timeconstraint constraints, state compaction, lifeline messages.

uml.interaction_overview@1

Flowchart of interaction steps; flow nodes may reference other workspace views and render a ref badge; targets are not expanded.

uml.interaction_overview@2

uml.interaction_overview@1 plus: inline expansion of referenced interactions; x_use gates/arguments.

uml.profile@1

UML 2.5.1 profile diagrams: uml.metaclass/uml.stereotype, uml.extension (filled triangle), uml.application («apply»).
