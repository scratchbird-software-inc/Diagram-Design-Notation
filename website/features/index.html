Features

A shared model, many ways to see it.

Create connected diagrams with short notation, reusable definitions and method-specific rules.

Readable notation

Indentation gives the document structure. Write only the values you need to override.

Multiple views

Reuse the same definition in several views without duplicating its identity or facts.

Progressive design

Start with a name, draft body or incomplete data. Add structure as the design develops.

Scoped defaults

File settings, type-scoped CSS and fixed standard defaults keep simple diagrams short.

Paper and stationery

Add editable notes, layered pads, shaped shadows and coloured attachments to your design.

Standard appearance dialogs

Use compact controls, local font resources, repeatable textures and user/company presets.

Separate data

Bind views to named datasets and receive coherent host-supplied data updates.

151 bounded profiles

Native DDN plus UML, Chen, flowcharts, charts, matrices, timelines, maps and more.

Three standalone utilities

UtilityPurposeTry it
ViewerRead-only display, navigation, inspection and supported snapshot capture. It may receive supplied live updates.Open viewer
Visual designerUses the viewer and adds editing, legal palettes, source changes, history and lifecycle actions.Open designer
VerifierChecks source, references, properties, profile rules and completeness for the requested scope.Open verifier

The utilities work locally in the browser. Multi-user participation, meetings, media and coordinated server services belong to Weaver.

Each method keeps its own rules

A native DDN ERD is distinct from Chen or crow’s-foot notation. Selecting a profile sets the palette, connection rules and projection. A familiar symbol does not silently import another method’s assumptions.
