                kind push-pin
                color "#c63f54"
view Workshop as ddn@1
    use Idea

Omit colour, size, position or angle to use their defaults. Paper notes and pads default to pale yellow; explicit file colour overrides CSS, and CSS overrides the standard. Use shadow none, paper plain, or an empty decorations list to remove an effect. The same appearance can be saved as a scoped default and reused.

Shadow settings include colour, opacity, blur, lift, offset and spread. Attachment positions use lt ct rt lm cm rm lb cb rb for left/centre/right and top/middle/bottom. Numeric size and offsets use logical pixels; rotation uses degrees. SVG and PNG exports contain the same local vector effects.
