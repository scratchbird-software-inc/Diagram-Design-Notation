VSM symbol library

The value-stream-mapping symbol set on one sheet: processes, inventories, flows, kaizen bursts and information icons.

Why use it?

A shared symbol sheet ends the "what does that triangle mean" detour in every mapping workshop.

When it helps

Reference while drawing or reviewing any value stream map.

How to read it

  • Each symbol is labelled with its VSM name; find the mark from your map and read its meaning here.
  • Symbols are drawn at working size — what you see is what renders in a real map.

What you need

  • None — this is a reference sheet

Things to check

  • Do not invent private symbols when the standard set covers the case.
  • Do not mix icon styles inside one map.
Scope of this diagram

The declared symbol library; meanings follow common VSM practice, no external certification implied.

Work with the converted example

  1. Open the viewer and select map. Inspect the rendered view and its source.
  2. Open the designer. Keep the selected profile and inspect its legal palette and property controls.
  3. Change one displayed title or an appropriate data value. Check the live update in the resulting diagram.
  4. Run the verifier and review its diagnostics before moving complete content into review.
  5. Download your edited DDN source to retain the change.

The example uses the indentation-based ddn-next-1 dialect. The language guide explains reusable definitions, dotted data rows and explicit property blocks.
