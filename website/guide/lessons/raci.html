Matrices, tables and analysis panels

RACI responsibility matrix

Who is Responsible, Accountable, Consulted and Informed for each deliverable, one letter per person per row.

matrix.raci@1New DDN source
Open viewerOpen designerRun verifierDownload DDN

Why use it?

Accountability fails when it is shared; the matrix makes "exactly one A per row" something a validator can check.

When it helps

Assigning work packages, approvals or escalation ownership.

How to read it

  • Read row by row: each deliverable needs exactly one A.
  • R does the work, A answers for it, C is asked, I is told.

What you need

  • The deliverables
  • The people
  • The letters per cell

Things to check

  • Do not allow two As on one row.
  • Do not confuse C (consulted before acting) with I (told after).
Scope of this diagram

Declared assignments with the one-accountable rule validated; the matrix does not enforce the work itself.

Work with the converted example

  1. Open the viewer and select raci. Inspect the rendered view and its source.
  2. Open the designer. Keep the selected profile and inspect its legal palette and property controls.
  3. Change one displayed title or an appropriate data value. Check the live update in the resulting diagram.
  4. Run the verifier and review its diagnostics before moving complete content into review.
  5. Download your edited DDN source to retain the change.

The example uses the indentation-based ddn-next-1 dialect. The language guide explains reusable definitions, dotted data rows and explicit property blocks.
