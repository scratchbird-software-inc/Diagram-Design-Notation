What this diagram shows

The Tabler open icon set applied to a small system map — one of the bundled packs, shown end to end.

Why use it?

A neutral, consistent stroke set keeps mixed-vendor diagrams from becoming logo soup.

When is it useful?

Documentation where vendor-neutral symbols are policy or good taste.

How to read this example

  1. Each node declares its Tabler glyph by name; the pack ships in the runtime.
  2. Stroke weight and sizing follow the publication format, not the icon source.

How to author this view

  1. Open website/examples/basics/106-tabler-icons.ddn and locate view net. This selects existing data; it is not a stored SVG.
  2. Inspect the network.basic@1 profile and graph projection. Read the bindings before changing any value.
  3. Use the source-file picker or select a diagram element to find its declaration. Edit labels or values deliberately; keep identifiers stable unless all references are updated.
  4. Apply the source, inspect diagnostics, and compare the expected result. Export the SVG only after a successful render.

Boundaries and common mistakes

The bundled Tabler subset as declared in the registry; upstream set changes are not tracked live.

  • Do not hardcode pixel assumptions — the publication format owns sizing.
  • A missing glyph name fails the render; check diagnostics before blaming layout.
