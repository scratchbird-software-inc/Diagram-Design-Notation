Value stream map — current state

A lean value stream: process boxes with data, inventory triangles between them, information flow above, the timeline ladder below.

vsm.basic@1New DDN source
Open viewerOpen designerRun verifierDownload DDN

Why use it?

Lead time hides in the gaps between processes; the map adds up processing time versus waiting time on one page.

When it helps

Lean improvement: before any kaizen, draw the current state as measured.

How to read it

  • Process boxes run left to right; triangles are inventory (waiting) between them.
  • The ladder at the bottom separates value-adding time from waiting — the ratio is the point.

What you need

  • The process steps with measured times
  • Inventory levels between steps
  • The information flow that triggers work

Things to check

  • Do not draw the future state first — a map of wishes improves nothing.
  • Times are measurements, not targets; mark estimates honestly.
Scope of this diagram

Declared map with VSM symbol validation; the arithmetic of the timeline is shown from declared numbers, not re-measured.

Work with the converted example

  1. Open the viewer and select map. Inspect the rendered view and its source.
  2. Open the designer. Keep the selected profile and inspect its legal palette and property controls.
  3. Change one displayed title or an appropriate data value. Check the live update in the resulting diagram.
  4. Run the verifier and review its diagnostics before moving complete content into review.
  5. Download your edited DDN source to retain the change.

The example uses the indentation-based ddn-next-1 dialect. The language guide explains reusable definitions, dotted data rows and explicit property blocks.
