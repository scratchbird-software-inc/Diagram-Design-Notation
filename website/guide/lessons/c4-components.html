How to author this view

  1. Open website/examples/basics/25-c4-views.ddn and locate view component. This selects existing data; it is not a stored SVG.
  2. Inspect the c4.component@1 profile and graph projection. Read the bindings before changing any value.
  3. Use the source-file picker or select a diagram element to find its declaration. Edit labels or values deliberately; keep identifiers stable unless all references are updated.
  4. Apply the source, inspect diagnostics, and compare the expected result. Export the SVG only after a successful render.

Boundaries and common mistakes

C4-style equivalent; not a code-structure certification.

  • Do not invent components that have no code counterpart.
  • Do not let every component talk to every other — that is a missing component.
