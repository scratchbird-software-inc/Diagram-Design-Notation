UAF strategic viewpoint (St)

The UAF Strategic viewpoint: enterprise phases, capabilities and the strategic map that says which capability arrives when.

uaf.strategic@1New DDN source
Open viewerOpen designerRun verifierDownload DDN

Why use it?

Portfolio arguments need a picture where capability gaps are visible before they are budget lines.

When it helps

Enterprise architecture roadmapping and capability planning.

How to read it

  • Rows and columns follow the declared strategic taxonomy; each cell/box is a capability or phase claim.
  • Trace from a capability to the phases that deliver it before agreeing dates.

What you need

  • The capabilities
  • The strategic phases
  • The mapping between them

Things to check

  • Do not promise a capability in a phase with no project behind it.
  • A capability with no owner is a slide, not a plan.
Scope of this diagram

Declared strategic model with UAF profile validation; portfolio feasibility is not assessed.

Work with the converted example

  1. Open the viewer and select strategic. Inspect the rendered view and its source.
  2. Open the designer. Keep the selected profile and inspect its legal palette and property controls.
  3. Change one displayed title or an appropriate data value. Check the live update in the resulting diagram.
  4. Run the verifier and review its diagnostics before moving complete content into review.
  5. Download your edited DDN source to retain the change.

The example uses the indentation-based ddn-next-1 dialect. The language guide explains reusable definitions, dotted data rows and explicit property blocks.
