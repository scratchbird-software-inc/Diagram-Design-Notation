Paused placement — retaining the current scene

website/examples/live/pinned-patterns.ddn # paused

technique

What this diagram shows

Auto-placement switched off for a view: the engine retains the current positions and refuses to re-derive them.

Why use it?

A reviewed layout is a reviewed artefact — pausing freezes what was approved while the model keeps evolving underneath.

When is it useful?

Baselined publication views, and any diagram whose composition was agreed in a review.

How to read this example

  1. The scene renders retained positions; new elements still need a declared seed position.
  2. The info diagnostic (auto-placement paused) is the engine stating the contract, not an error.

Information to gather first

  • The model
  • The retained positions
  • Seed positions for anything new

How to author this view

  1. Open website/examples/live/pinned-patterns.ddn and locate view paused. This selects existing data; it is not a stored SVG.
  2. Inspect the ddn@1 profile and graph projection. Read the bindings before changing any value.
  3. Use the source-file picker or select a diagram element to find its declaration. Edit labels or values deliberately; keep identifiers stable unless all references are updated.
  4. Apply the source, inspect diagnostics, and compare the expected result. Export the SVG only after a successful render.
Actual view declaration
view paused "Pause placement / retain the current scene" {
    data: [@network]; format: @patterns.shared;
    layout { auto_place: false; }
    place @network.hub { at: [580px, 400px]; size: [270px, 170px]; }
    place @network.store { at: [930px, 400px]; size: [270px, 170px]; }
    // On first render a seed is needed; the live component then retains it.
}

Boundaries and common mistakes

Retention of declared/current positions with auto_place off; it preserves positions, not model semantics.

  • Do not pause early — pausing freezes today's accidents along with today's decisions.
  • A new element with no seed position under paused placement is a declaration gap you must fill.
