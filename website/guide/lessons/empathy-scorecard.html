What this diagram shows

An empathy map — what a user says, thinks, does and feels — plus a scorecard variant in the same source.

Why use it?

The four-quadrant map keeps a team from designing for itself.

When is it useful?

Early discovery for a feature or service.

How to read this example

  1. Quadrants are observation categories, not personality types.
  2. Entries are evidence or declared hypotheses — mark which.

Information to gather first

  • The user
  • Observed statements and behaviours
  • Inferred feelings, marked as inferred

How to author this view

  1. Open website/examples/basics/34-empathy-scorecard.ddn and locate view empathy. This selects existing data; it is not a stored SVG.
  2. Inspect the canvas.empathy@1 profile and panels projection. Read the bindings before changing any value.
  3. Use the source-file picker or select a diagram element to find its declaration. Edit labels or values deliberately; keep identifiers stable unless all references are updated.
  4. Apply the source, inspect diagnostics, and compare the expected result. Export the SVG only after a successful render.

Boundaries and common mistakes

Declared empathy content; the map organises evidence, it does not collect it.

  • Do not present a hypothesis as an observation.
  • Do not run an empathy session about a demographic instead of a person.
