SysML parametric diagram

Constraint blocks (equations) bound to the value properties of blocks — the system's arithmetic made explicit.

sysml.parametric@2New DDN source
Open viewerOpen designerRun verifierDownload DDN

Why use it?

Performance claims stop being adjectives when the balance equations are drawn and bound to real properties.

When it helps

Trade studies: mass, power, flow, cost — any "the numbers must add up" argument.

How to read it

  • Rounded boxes are constraint properties (equations); small circles are parameters bound to values.
  • Binding connectors wire equation parameters to block value properties.

What you need

  • The constraint blocks (equations)
  • The value properties they constrain
  • The bindings

Things to check

  • Do not leave a parameter unbound — an equation with a free variable checks nothing.
  • Units are part of the property; a binding across unit systems is a defect.
Scope of this diagram

Declared constraints and bindings; solving or simulating the equations is out of scope.

Work with the converted example

  1. Open the viewer and select parametric. Inspect the rendered view and its source.
  2. Open the designer. Keep the selected profile and inspect its legal palette and property controls.
  3. Change one displayed title or an appropriate data value. Check the live update in the resulting diagram.
  4. Run the verifier and review its diagnostics before moving complete content into review.
  5. Download your edited DDN source to retain the change.

The example uses the indentation-based ddn-next-1 dialect. The language guide explains reusable definitions, dotted data rows and explicit property blocks.
