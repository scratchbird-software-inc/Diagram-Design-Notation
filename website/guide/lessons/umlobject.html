UML object diagram — instance snapshot

Instances at a moment: objects with slot values linked as the classifiers permit — a snapshot, not a schema.

uml.object@1New DDN source
Open viewerOpen designerRun verifierDownload DDN

Why use it?

One concrete snapshot falsifies a wrong class diagram faster than an hour of abstract review.

When it helps

Testing a class model against a real example, or documenting a known configuration.

How to read it

  • Underlined instance:Classifier names are objects; slots show current values.
  • Links are instances of associations — check them against the class diagram.

What you need

  • The objects
  • Their slot values
  • The links

Things to check

  • Do not invent a link the class model forbids.
  • A snapshot shows one moment — do not read it as the only state.
Scope of this diagram

Declared instances; conformance to a class model is documented, not re-derived here.

Work with the converted example

  1. Open the viewer and select objects. Inspect the rendered view and its source.
  2. Open the designer. Keep the selected profile and inspect its legal palette and property controls.
  3. Change one displayed title or an appropriate data value. Check the live update in the resulting diagram.
  4. Run the verifier and review its diagnostics before moving complete content into review.
  5. Download your edited DDN source to retain the change.

The example uses the indentation-based ddn-next-1 dialect. The language guide explains reusable definitions, dotted data rows and explicit property blocks.
