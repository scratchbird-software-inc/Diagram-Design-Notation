What this diagram shows

A flowchart using the complete ISO 5807 vocabulary: the classic symbols plus manual input, preparation, display, delay, loop limits, merge/extract, card, collate, sort and parallel mode.

Why use it?

Flowcharts are the most misused notation in the world — the full symbol set says exactly what each step is.

When is it useful?

Documenting procedures for a general audience.

How to read this example

  1. Read top to bottom following the arrows; every symbol has one meaning.
  2. Decisions have exactly the branches their labels claim.

Information to gather first

  • The steps and their types
  • The branches
  • Start and end points
