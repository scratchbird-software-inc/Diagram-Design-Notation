What this diagram shows

The distribution family beyond the histogram: violin shapes, density curves, Q-Q plots and quantile dots from one record set.

Why use it?

Shape questions need shape tools — each of these shows what averages and even histograms smooth away.

When is it useful?

Comparing distributions, checking normality, reading tails.

How to read this example

  1. The violin mirrors the density; the Q-Q compares against the theoretical line.
  2. Quantile dots are records, never a smoothed invention.

Information to gather first

  • The values
  • The comparison target (normal, or another group)
  • The variant that answers your question

How to author this view

  1. Open website/examples/basics/62-distribution-charts.ddn and locate view violin. This selects existing data; it is not a stored SVG.
  2. Inspect the chart.violin@1 profile and chart projection. Read the bindings before changing any value.
  3. Use the source-file picker or select a diagram element to find its declaration. Edit labels or values deliberately; keep identifiers stable unless all references are updated.
  4. Apply the source, inspect diagnostics, and compare the expected result. Export the SVG only after a successful render.

Boundaries and common mistakes

Declared kernels and quantiles from the records; no significance testing.

  • Do not read a KDE bandwidth as data.
  • Do not conclude normality from a pretty Q-Q alone.
