Field guide / Matrices, tables and analysis panels

Matrices, tables and analysis panels

Categorical status matrix

A status board: cells coloured by category (ok/degraded/down/unknown) rather than number.

matrix.heatmap@1New DDN source
Open viewerOpen designerRun verifierDownload DDN

Why use it?

One glance answers "what is on fire" across many small services.

When it helps

Operations walls and release readiness boards.

How to read it

  • Categories are declared sets with declared colours.
  • Unknown is a category, not a colour to ignore.

What you need

  • The services/axes
  • The category set
  • A colour per category

Things to check

  • Do not add a category without a colour and a meaning.
  • Do not let stale data look fresh — timestamp the board.
Scope of this diagram

Declared categories from declared data; no live probing.

Work with the converted example

  1. Open the viewer and select heat_categories. Inspect the rendered view and its source.
  2. Open the designer. Keep the selected profile and inspect its legal palette and property controls.
  3. Change one displayed title or an appropriate data value. Check the live update in the resulting diagram.
  4. Run the verifier and review its diagnostics before moving complete content into review.
  5. Download your edited DDN source to retain the change.

The example uses the indentation-based ddn-next-1 dialect. The language guide explains reusable definitions, dotted data rows and explicit property blocks.
