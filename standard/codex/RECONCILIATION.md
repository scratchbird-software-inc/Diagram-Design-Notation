The following choices are inferred and frozen for this candidate, rather than attributed to the owner:

- Cell defaults: left/top, automatic percentage, minimum 1 character and maximum 6 displayed lines. The owner's `19:6` was a notation example.
- Character measurement: default-font zero advance and line-height. Pixel remainders use descending fractional remainder, ties left-to-right.
- Paper recipes: A4 portrait for PDF/DOCX/ODT; content extent for flow/data outputs; the general publication figure default is retained.
- Normalized JSON separates reference names from titles and core payloads from retained metadata. It is not another source notation users need to learn.
- Previously open metadata records receive explicit typed fields based on retained validators, plus bounded inferred shapes where the old contract had none. Real arbitrary application data remains a typed JSON value under a declared data/schema boundary.
- Templates normalize parameterized property settings into their own settings map; expansion validates the resulting target property.
- The reference harness checks command transitions and supplied verification evidence but does not authenticate the user or replace the product verifier.

Historical packs remain intact as evidence. Their generated schemas must not be loaded alongside this pack as competing authorities. The maintained project source has not been changed.

## New-document modes — 25 October 2026

Owner-requested P06651 `workarea.mode` adds explicit `standalone` to the unreleased contract. Omitted `mode` resolves to `workarea`, preserving existing behavior and every prior default. Standalone exposes one view/document from the entry-file include closure; its extent follows the view and has no surrounding workarea navigation. More than one view is structurally invalid; unfinished zero-view draft/in-progress documents remain editable but cannot pass review. Included workarea settings remain inactive. This is an opt-in extension, not a reinterpretation of existing files or a commercial permission capability.
